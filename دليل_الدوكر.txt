■ الملفات التي أنشأناها
═════════════════════════

   ١. Dockerfile.backend       — صورة الخادم الخلفي
   ٢. Dockerfile.frontend      — صورة الواجهة
   ٣. docker-compose.yml       — يربط الخادمين ببعض
   ٤. .dockerignore            — يمنع نسخ الملفات غير الضرورية
   ٥. .env.docker.example      — قالب ملف البيئة
   ٦. frontend/nginx.conf      — إعدادات إنجن إكس للواجهة


■ المتطلبات قبل التشغيل
═════════════════════════

   ١. تثبيت Docker Desktop على جهازك:
      https://www.docker.com/products/docker-desktop/

   ٢. التأكد من تشغيله (الأيقونة في شريط المهام)


■ خطوات التشغيل
═════════════════

   الخطوة ١ — أنشئ ملف البيئة:

      انسخ الملف .env.docker.example إلى ملف اسمه .env
      وضع فيه مفاتيحك الحقيقية:

         • OPENAI_API_KEY      — مفتاح أوبن إيه آي
         • GEMINI_API_KEY      — مفتاح جيمناي
         • JWT_SECRET_KEY      — مفتاح عشوائي للجلسات
         • ENCRYPTION_KEY      — مفتاح فيرنت للتشفير

   الخطوة ٢ — افتح موجه الأوامر في مجلد المشروع وشغّل:

         docker compose up -d --build

      هذا الأمر:
         • يبني صورة الخادم الخلفي (يأخذ ٥-١٠ دقائق أول مرة)
         • يبني صورة الواجهة (يأخذ ٢-٣ دقائق)
         • يشغّل الخادمين في الخلفية

   الخطوة ٣ — افتح المتصفح:

         http://localhost

      هذا هو الرابط الوحيد اللي تحتاجه. كل شي يمر من هنا.


■ الأوامر الأساسية
════════════════════

   عرض السجلات الحية:
      docker compose logs -f

   عرض سجلات الخادم الخلفي فقط:
      docker compose logs -f backend

   إيقاف النظام:
      docker compose down

   إيقاف وحذف البيانات المخزنة (تحذير: يمسح القاعدة):
      docker compose down -v

   إعادة البناء بعد تعديل الكود:
      docker compose up -d --build

   الدخول لطرفية الخادم الخلفي:
      docker compose exec backend bash


■ المنافذ المستخدمة
═════════════════════

   80     — الواجهة (الرابط الذي يفتحه المستخدم)
   8000   — الخادم الخلفي (مكشوف للتطوير)
   5789   — خادم منصة إكس (مكشوف للتطوير)
   5000   — خادم تسجيل الدخول الجماعي
   5990   — خادم توليد الهويات


■ البيانات الدائمة
═══════════════════
الدوكر يحفظ هذي الأشياء حتى لو حذفت الحاويات:

   moj_data           — قاعدة البيانات
   moj_cookies        — كوكيز حسابات إكس
   moj_identity_imgs  — الصور المولّدة من جيميناي
   moj_uploads        — ملفات المستخدمين

   لمعرفة مكانها على جهازك:
      docker volume inspect موج_data


■ ملاحظات أمنية مهمة
═══════════════════════

   • لا ترفع ملف .env إلى قِت‌هَب أبداً
   • مفاتيح أوبن إيه آي وجيمناي تكلّفك مال — اضبط حدود في حساباتك
   • الكوكيز في الـ volume هي توكِنات دخول حقيقية، تعامل معها
     كأنها كلمات سر


■ المشاكل الشائعة وحلولها
═══════════════════════════

   ◆ "port 80 is already in use"
     ─ نفّذ: docker compose down ثم أعد المحاولة
     ─ أو غيّر منفذ الواجهة في docker-compose.yml:
        "8080:80" بدل "80:80" ثم افتح localhost:8080

   ◆ "OPENAI_API_KEY not set"
     ─ تأكد من وجود ملف .env في نفس مجلد docker-compose.yml
     ─ تأكد إن المفتاح فعلاً موجود وصحيح

   ◆ Playwright يفشل (لا يقدر يفتح المتصفح)
     ─ الـ Dockerfile.backend يثبت Chromium تلقائياً
     ─ لو فشل، نفّذ:
        docker compose exec backend playwright install chromium

   ◆ القاعدة فاضية
     ─ يصير لو حذفت الـ volume
     ─ سجّل مستخدم جديد من الواجهة وأعد إضافة حساباتك

   ◆ "no such file: init_database.py"
     ─ يعني .dockerignore تجاهل الملف
     ─ تأكد إن init_database.py في جذر المشروع


■ النشر على خادم سحابي (اختياري)
═══════════════════════════════════
لو تبي تنشر النظام على خادم حقيقي (Linode, DigitalOcean, AWS):

   ١. ثبّت Docker على الخادم
   ٢. ارفع ملفات المشروع (بدون .env)
   ٣. أنشئ .env على الخادم بمفاتيحك
   ٤. شغّل: docker compose up -d --build
   ٥. اربط دومين بالخادم
   ٦. أضف شهادة SSL (Let's Encrypt) عبر Caddy أو Traefik
