📖 مقدمة

يوفر هذا النظام مجموعة شاملة من واجهات برمجة التطبيقات (APIs) للوصول إلى بيانات التغريدات المحفوظة وإدارة المراقبة التلقائية.

الوصول إلى التغريدات المحفوظة

إحصائيات شاملة للنظام

🤖 المراقبة

إدارة المراقبة التلقائية

📱 واجهات برمجة التطبيقات للتغريدات

الوصف: جلب آخر التغريدات المحفوظة في قاعدة البيانات

المعاملات الاختيارية:
  • limit (integer): عدد التغريدات (1-100، افتراضي: 10)
  • username (string): فلترة حسب اسم مستخدم معين
أمثلة:
GET /api/tweets/latest?limit=5
GET /api/tweets/latest?username=elonmusk&limit=3

الوصف: جلب جميع التغريدات المحفوظة لمستخدم معين

المعاملات:
  • username (مطلوب في الرابط): اسم المستخدم
  • limit (اختياري): عدد التغريدات (افتراضي: 20)
مثال:
GET /api/tweets/user/example_user?limit=10

الوصف: جلب تفاصيل تغريدة محددة باستخدام معرفها

المعاملات:
  • tweet_id (مطلوب في الرابط): معرف التغريدة
مثال:
GET /api/tweet/1234567890123456789
📊 واجهات برمجة التطبيقات للإحصائيات

الوصف: إحصائيات مفصلة عن قاعدة البيانات والمحتوى

البيانات المُعادة:
  • إجمالي التغريدات والمستخدمين
  • أكثر المستخدمين نشاطاً
  • اللغات الأكثر استخداماً
  • آخر التحديثات
🤖 واجهات برمجة التطبيقات للمراقبة

الوصف: معلومات عن مهام المراقبة التلقائية وسجلاتها

البيانات المُعادة:
  • قائمة جميع مهام المراقبة
  • آخر السجلات والأنشطة
  • إحصائيات المراقبة

الوصف: تشخيص مشاكل النظام والمراقبة

ملاحظة: يظهر التشخيص في الكونسول

🔢 رموز الاستجابة
رموز النجاح:
  • 200 نجح الطلب
  • 201 تم إنشاء المورد
رموز الخطأ:
  • 400 طلب غير صحيح
  • 404 المورد غير موجود
  • 500 خطأ في الخادم
💻 أمثلة على الاستخدام
JavaScript (Fetch):
fetch('/api/tweets/latest?limit=5')
  .then(response => response.json())
  .then(data => {
    console.log(data.data.tweets);
  });
Python (Requests):
import requests

response = requests.get(
  'http://localhost:5000/api/tweets/latest?limit=5'
)
data = response.json()
print(data['data']['tweets'])
cURL:
curl -X GET \
  "http://localhost:5000/api/tweets/latest?limit=5" \
  -H "Content-Type: application/json"
PHP:
$response = file_get_contents(
  'http://localhost:5000/api/tweets/latest?limit=5'
);
$data = json_decode($response, true);
print_r($data['data']['tweets']);
